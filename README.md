## How to Use This Repository

1. Open the required week folder.
2. Read the corresponding `README.md` for the experiment description and instructions.
3. Open the C source file for programming experiments.
4. Compile and execute the program using a suitable C compiler.
5. Refer to the PDF files and screenshots for supporting material, where available.

## Compile and Run C Programs

Install a C compiler such as GCC before executing the programs.

### Compile

```bash
gcc program.c -o program
```

### Run on Windows

```bash
program.exe
```

Alternatively, in Command Prompt:

```bash
.\program.exe
```

### Run on Linux

```bash
./program
```

Replace `program.c` with the actual source filename.
